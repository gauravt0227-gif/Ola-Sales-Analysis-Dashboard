🚖 Ola Sales Analysis Dashboard
A comprehensive Power BI dashboard analyzing ride-hailing service data for Ola, providing insights into booking patterns, revenue metrics, cancellation trends, and customer behavior.
📊 Project Overview
This project presents an interactive Power BI dashboard that analyzes over 103,000 bookings from Ola's ride-hailing service during July 2024. The dashboard provides actionable insights into operational efficiency, revenue generation, and customer satisfaction metrics.
🎯 Key Features
Dashboard Components

Ride Volume Analysis

Time-series visualization of booking trends
Daily ride volume tracking across the month


Booking Status Breakdown

Success rate: 62.05% (35M bookings)
Cancellation analysis by driver and customer
Driver availability metrics


Revenue Analytics

Total booking value: ₹35M
Payment method distribution (Cash, UPI, Credit Card, Debit Card)
Revenue trends over time


Customer Insights

Top 5 customer identification
Customer ratings analysis (avg: 3.99-4.01)
Ride distance patterns


Cancellation Analysis

Driver cancellations: 28,933 bookings
Top reasons for cancellations by drivers and customers
Cancellation rate trends

Booking Performance

Exceeding permitted passengers: 15.59%

Change of plans: 24.98%
